# Cloud Computing Concepts Reflection 

Cloud computing has become an important part of my everyday life because many of the apps and websites I use depend on cloud technology. One service that I use almost every day is Google Drive. I use it to save my school files, submit assignments, and open my documents on different devices whenever I need them. Google Drive is considered Software as a Service (SaaS) because users can access its features through a web browser or mobile app without having to install or manage the system behind it. It is also an example of a Public Cloud since Google offers the service to anyone with an internet connection.
Another cloud-based application that I use regularly is Facebook Messenger. It is also classified as SaaS because it provides messaging services directly to users without requiring them to manage servers or software. Messenger runs on a Public Cloud, making it possible for people from different parts of the world to communicate and share information online.
The third cloud service that I often use is Canva. It is another example of SaaS because it allows users to create presentations, posters, and other designs using online tools instead of installing professional design software. Canva also uses a Public Cloud deployment model because its services are accessible to anyone through the internet.
Version control is very important in cloud computing because many developers work on the same project at the same time. Without it, files can easily be overwritten, deleted, or replaced by mistake. Git and GitHub help keep a complete record of every change made to a project, making it easier to review updates, correct errors, and recover previous versions whenever needed.
GitHub also makes teamwork more efficient by allowing developers to work on separate branches before merging their changes into the main project. This helps reduce conflicts and keeps the project organized. Through this activity, I realized that cloud computing and version control go hand in hand in making collaboration easier, protecting project files, and ensuring that software development is more reliable and well-managed.
